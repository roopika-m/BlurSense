# 🔐 BlurSense AI – Privacy CCTV System

BlurSense AI is a real-time computer vision-based CCTV system that detects faces using OpenCV and automatically blurs them in unauthorized mode. It also sends instant Telegram alerts with snapshots.

---

## 🚀 Features
- Real-time face detection  
- Face blurring in unauthorized mode  
- Telegram alert notifications  
- Snapshot capture  
- Mode switching (Authorized / Unauthorized)  

---
